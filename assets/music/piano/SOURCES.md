# Piano music library

`music.provider: library` picks one track from this folder per project (by project id) and levels
it to -16 LUFS. Drop in any track you have the rights to use (YouTube Audio Library, Pixabay
Music, ...) and delete the ones you don't like.

Seed tracks: all CC0 (public domain, no attribution needed), found through the Openverse API.
